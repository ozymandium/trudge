Trudge
======

What does 7 reps at 60% mean? Is 3 reps at 50kg an improvement over 5 reps at 45kg?

Trudge computes 1-rep max equivalent (1RME) for every set during your workout, so you have a common baseline for effort. Data is tracked and parsed in a simple CSV. Has a couple pretty plots for tracking progress over time, and and CLI table generation to quickly pick a correct weight at the gym.
